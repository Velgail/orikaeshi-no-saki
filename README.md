# 折り返しの先へ

架空の青葉線8駅・単線の指令ゲームです。08:00は営業途中の引継ぎです。所定便は自動運行し、指令員は乱れに対する変更を指示します。実在鉄道の制御・労務判断には使えません。

## 起動とプレイ

1. ZIPを解凍します。
2. 解凍先で既存のNode.jsを使い `node server.mjs`。
3. ブラウザーで `http://127.0.0.1:8765` を開きます。終了はCtrl+C。

Windows/Mac/Linux共通。既存のPython 3なら `python3 -m http.server 8765 --bind 127.0.0.1`（Windowsでは`python`）でも起動できます。file:で直接開く方法は対象外です。プレイ時の外部API、CDN、フォント、通信は不要。ソフトウェアの追加インストールはしていません。

開始説明を閉じ、モードを選んで「運転開始」。「障害なし」は無操作で所定運行を観察できます。「障害シナリオ」は受信した報告に対して抑止解除、短縮、代走、交代などを指令します。未来の障害は予告しません。

1倍は実1秒＝ゲーム1秒。時計は整数1分ごと、次更新までの進捗を表示。60倍は実1秒＝ゲーム1分、240倍は実1秒＝ゲーム4分です。重大通知で必ず停止し、確認後も停止を維持。停止・1分送り、ルール閲覧時停止、背景タブから戻った時の追いつき禁止を備えます。入力中は進行しますが選択・入力・開いた詳細を保持します。

時計と進行操作は上部、選択と指令卓は右側に固定し、実行ボタンはスクロールする説明本文と別の専用フッターに表示します。配線図だけは実寸の横スクロールで読みます。「図で探す」でページを図へ戻し、図内の縦横を選択編成の実位置へ移動します。1165×747のブラウザー実画面で入れ子表、操作卓の非重複、車庫4線への移動を確認済みです。

## 朝からの配置と読む順序

森ヶ丘車庫4線に夜間4編成を留置。04:10点呼、車両準備、出庫、回送を同じエンジンで実行し、05:24から営業を開始します。全線は2編成の交互往復（約36分間隔）、西側補助は1編成、故障時に使う車庫予備が1編成。所要27分＋折返し・交代の余裕9分で全線の往復運用72分を構成します。補助は中央〜学園前を7分、復路まで5分で接続します。08:00には営業3編成が走行中、予備F4は車庫4線です。端駅への直置きや瞬間移動ではありません。

- 編成Fの親枠内に便の子表。便は時系列、過去・現在・次便を区別します。接続欄は開始前の未計算、開始後の予測、運行中、確定実績を分けて表示します。
- 「駅別の比較表」を開くと、駅を行、所定着/発・変更着/発・実着/発・番線を列にした表が出ます。文章の全駅羅列は使いません。閉鎖・抑止中の変更見込は未定です。
- 担当乗員を押すと、その人の親枠が開きます。勤務残量・実働等の小表、朝からの乗務/便乗/準備/休憩/待機の区間子表、所定担当表を読みます。法令・既往履歴はさらに折り畳みます。
- 車庫親枠の留置線子表で収容・準備・経路使用を確認します。編成ごとの「なぜここにいる？」と朝の引継ぎ履歴で出庫→回送→営業を追えます。

便A/B/D、編成F、乗員Cは別のID。Tは物理編成の操作対象です。元所定は不変、変更計画と実績は別データです。「この便以後の運用を代走編成へ」は以後の人車接続をまとめて変更し、所定時刻・乗員行路・抑止・運休を維持します。最初の対象始発には実在する編成と適格な乗員が必要で、後続便も所在地と時間を実判定します。

復旧はダイヤの位相を起点とする所定72分1周期の全停車・発着が定時、翌周期の人車・進路接続も成立すること。既に過ぎた翌便も定時実績を確認します。便を削除・時刻を移して成功にはできません。適格な代走は許容します。

同じ15:12（引継ぎ後432分）まで観察します。4分ごと各駅1人、容量80人。朝からの乗客も引継ぎ、目的地到着だけ輸送完了です。短縮終着では元目的地を保持して乗換待ち。待ち人分は駅待ちだけを毎分加算。08:00以前の到着・待ち・超勤は今回の採点から除外します。採点は到着×10−待ち人分÷100−評価超勤分＋復旧500＋復旧から終了までの分×3です。

## 設備・勤務・保存

駅間は両方向共用1閉塞。番線別の線分、分岐器stem/normal/reverse、進入/出発経路、対応信号設備、鎖錠資源を定義し、判定と図が同じIDを参照します。逆向き出発経路がある現在番線だけで反転可能。駅の可否flagはありません。中立枠＋矢印は信号設備の存在・方向であり実現示ではありません。可用性は別表です。森ヶ丘車庫は西喉部の接続分岐器と鎖錠を営業列車と共有。準備5分、許可された経路の出入庫3分、担当乗員と空き番線が必要です。一般の入換・代用閉塞・手信号は未実装です。

BASE-JP-RAIL-2026：通常制、届出済み架空36協定（日2時間/月45時間/年360時間）、特別条項・33条例外・鉄道の休憩/予備勤務特例なし。連続乗務180分、次勤務11時間は架空社内安全規程です。資格・適性も別に判定します。法情報はユーザー提供一次資料（確認日2026-10-04）を参照し、実際の会社の制度や法的判断を保証しません。

朝班12名は04:10から実働8時間＋所定実休憩の勤務を前向きに設計し、正常時は全員実働480分で所定退勤。後続8名は11:00出勤し後続便を担当します。出勤場所は各担当拠点、所属基地は森ヶ丘。勤務前・終業後は実働外、準備・業務便乗・指示待機は実働。終着後の後処理2分も実働で、解放後だけ休憩。休憩前後に業務がある実区間で法34条の45/60分を確定し、末尾休憩は充足に使いません。予測不足は警告、終業時に確定します。

過去は2026-04-01〜10-03の日別勤務を保持。直前週は9/28〜10/1に各420分、10/2・10/3非勤務。月・年時間外0と前勤務終了はその履歴から導出。朝の実績は04:00からのエンジン再生です。所定終業超過と法定時間外は別表示し、今回発生した実働1分の和集合を1点だけ減点。先行分は減点しません。未実行拒否にも違反実績・減点を付けません。合法超勤は継続可、確定違反はゲーム失格（法律の処分ではない）。賃金は適正支払の前提です。

保存形式8。ブラウザーのローカル領域1件に車庫・移動経路・予約・乗客・勤務を含め保存。旧版、所定/先行履歴改変、経路・人車・台帳矛盾を拒否し現在の状態を保持します。月/年替わり台帳移行、実ダイヤの0時跨ぎ、SPECIALは未実装です。
