# 折り返しの先へ

架空の青葉線8駅・単線を担当する日本語の鉄道運転整理ゲームです。所定ダイヤが編成・乗務員を自動で運びます。プレイヤーは障害時の抑止解除、短縮、臨時運行、代走と交代を指令します。実在路線の制御や労務判断には使えません。

## 解凍から起動

1. `orikaeshi-no-saki.zip`を任意のフォルダーに解凍。
2. そのフォルダーで、既にあるNode.jsを使って`node server.mjs`。
3. 一般的なデスクトップブラウザーで`http://127.0.0.1:8765`を開く。終了はターミナルでCtrl+C。

Windows / Mac / Linux共通です。Nodeがない場合は、既にあるPython 3で`python -m http.server 8765 --bind 127.0.0.1`（環境により`python3`）も使えます。新しいソフトウェアのインストールは不要な構成です。HTMLをダブルクリックするfile:起動はES modulesのため対象外。プレイ時の外部ネットワーク、外部フォント、CDN、APIは使いません。

## 最初の操作

開始画面を閉じ、モードを選んで「運転開始」。平常便の発車操作は不要です。「障害なし・所定運行観察」は4周期の正常運行を無操作で見られます。「障害シナリオ」は所定運行から始まり、届いた現場報告に対して指令します。

1倍は実1秒＝ゲーム1秒です。ゲーム内部は整数1分のtickで、時計は1分ごとに更新、次tickまでの残りを表示します。60倍は実1秒＝ゲーム1分、240倍は実1秒＝ゲーム4分。重要報告の境界で必ず停止し、確認しただけでは再開しません。停止・1分送りも使えます。ルール閲覧と非表示タブは停止し、戻っても追いつき進行しません。入力中は進行しますが、選択・行先・指令・開いた便／乗員詳細は保持します。

指令卓で編成運用T、対象便A/B、指令、必要なら行先・乗員を選び、理由と次便接続を読んで実行します。「図で探す」は選択編成の現在駅へ横スクロールします。常時見える時計・速度操作と右操作卓を使って計画できます。重大報告は通常の操作通知とは別に保持します。

故障後に運行中便が安全抑止された場合は、変更計画を確認して「抑止解除」が必要です。全停止のまま待つことも、短縮・代走で輸送をつなぐこともできます。接続不足の便は勝手にワープせず待機し、編成と人の所在を表示します。具体的な攻略は通常説明から分けた[strategy.md](strategy.md)にあります（ネタバレ）。

## 所定・変更計画・実績

元所定は開始前から存在する72分周期です。全線便は中央から周期00分発27分着、逆方向36分発63分着。西側補助便は中央32分発・学園前39分着、学園前44分発・中央51分着。列車番号A/Bと物理的な編成F、乗務員Cを分け、Tは編成運用の操作対象に使います。元所定の編成・乗務員行路は不変、変更計画と実発着は別の列に表示します。

所定便は駅間3分、中間停車1分、終着反転準備3分。終端で交代・後処理2分と所定自由休憩、学園前で補助便の乗員が折返しを担当します。始発駅に人車がいなければ運行不能です。進入・続行・終着反転を満たす番線を予約し、他列車と同時に同じ閉塞・番線・構内進路資源は使えません。

変更計画の抑止は解除まで持続。運行中の便を別編成へ再割当することはできません。短縮や運休は実担当便に作用します。代走中の便を元編成へ戻す操作は拒否し、後続便を変更します。臨時旅客／回送と便乗は実際の移動・時間・鎖錠を伴います。交代は駅で抑止し、交代設備のある駅に実在する勤務可能な乗員を使います。

復旧は物理的な開通ではなく、**元所定72分1周期の全停車・発着が定時、翌周期の人車・進路接続も成立見込**で判定します。予測は現在受信済みの通行条件を固定して同じエンジンで確認し、未発生の事故を知りません。適合する代走人車も許容します。所定便を削除したり時刻を遅らせて成功にはできません。

全案を12:48（開始から288分）まで観察します。4分ごとに各駅1人が異なる目的地へ発生、1列車の容量80人。短縮終着で降りた客は元目的地を維持して待ち、乗換後の目的地到着だけが輸送完了です。結果は到着人数・未着・駅待ち人分・復旧時刻・超勤を比較。評価＝到着人数×10−待ち人分÷100−評価対象超勤分＋復旧時500＋復旧から観察終了までの分×3（最後の項は復旧時のみ）。採点は法律上の処分ではありません。

## 設備と配線

駅間は両方向共用1閉塞の単線です。番線別の物理線分、ポイントのstem/normal/reverse、場内／出発経路、対応信号、鎖錠資源は[equipment.js](equipment.js)で定義。判定と描画は同じIDを参照します。分岐側同士を直結する不正経路は認めません。

中央・森ヶ丘は本線側の出発経路があり、到着向きの反対へ戻れます。桜町1番線は西着・東発、2番線は東着・西発で、逆向きの出発信号／列車進路がありません。学園前1/4番線などは両方向出発可能です。駅別の折返可否flagは使いません。図は単線、段階的な分岐、平行番線、ホーム、車止めと線路上の列車を描きます。未実装の車庫線は描かず、予備F3/F4は森ヶ丘の駅番線に待機します。

中立枠＋矢印は信号設備の存在と方向。実際の停止／進行現示はモデル化しません。別表の「設定可能」は経路可用性で、発車時に経路と分岐器・到着番線を予約し鎖錠します。通常列車進路の運転のみを対象とし、入換・代用閉塞・手信号は実装しません。世界の単線駅がすべてこの設備であるとは主張しません。

図は横2660pxで文字を14pxのまま保持し、縮小全景に押し込めません。狭いデスクトップでは横スクロールと「図で探す」を利用。1160×746や1280×800の実ブラウザーでの可読性・操作性は親側の今回版検品が必要です。

## 勤務モデル

BASE-JP-RAIL-2026。日本の労働基準法の一般原則を参考にした架空会社です。通常制、届出済み36協定の日2時間・月45時間・年360時間、特別条項なし、法定休日労働0日、33条災害例外なし、乗務員の休憩・予備勤務特例は不使用。月100時間や年720時間まで使える制度ではありません。連続乗務180分と次勤務まで11時間は**架空社内安全規程**です。適性・資格・有効期限も時間枠とは別に作用します。

ゲーム内1分＝勤務1分。先行8名と後続8名に別々の所定勤務を設定しています。先行勤務は担当する便の最終後処理終了（予備は12:48）で終業し、所定の実働8時間になるよう始業時刻を行路と途中休憩から設計しています。先行区間は30分の準備・待機、60分の自由休憩、その後の準備・待機です。ゲーム中は所定乗務、終端後処理2分、途中の自由休憩30分を実行し、各人の始業・終業・担当便・実績は乗務員詳細で確認できます。正常4周期では先行8名が実働480分で終業し、予定外超勤は0です。後続8名は11:20まで勤務前（実働0）、実際の拠点に所在し、後続便を担当します。終業後の再呼出しはできません。

架空履歴は2026-04-01〜10-03の日別記録を保持します。通常は平日480分・休憩60分、週末非勤務。直前週は9/28〜10/1の4勤務各420分・休憩60分、10/2・10/3は非勤務です。週・月・協定年・過去5か月の時間外はこの履歴から0分となります。勤務日は個人カレンダーで、当日10/4は法定休日ではありません。協定年は2026-04-01〜2027-03-31、週起算は月曜、日本時間。保存形式7は旧保存と改変された先行履歴を拒否します。

乗務、準備、呼出し対応待機、業務便乗は実働。終着後の後処理2分は実働。その後、中央・森ヶ丘で業務から解放された実休憩を取り、中断時は経過した解放分のみ取得。連続乗務リセットは30分以上、29分の実休憩量とは別の判定です。実働6時間超なら途中休憩45分、8時間超なら60分。勤務中の不足は予測警告で、終業時に確定。勤務後の休憩で穴埋めしません。終業済みの人は再投入不可、結果画面でも勤務未完了を自動終業しません。

所定終業超過と法定時間外は別表示。日／週時間外は二重計上せず、協定の最小残量・次終着と後処理までの余裕を確認します。評価対象超勤はプレイ中の法定時間外増分と所定終業超過の実働分の和集合です。同じ1分は一度だけ1点減点し、初期履歴は減点しません。予測拒否は実績・減点・違反を加えません。確定した法令・協定違反／社内安全規程違反はゲーム失格です。賃金は適正に支払われるシナリオ前提で、減点は賃金の代替ではありません。

この版は日中固定シナリオです。月替わり・協定年替わりの台帳移行、二暦日にわたる実ダイヤ、SPECIAL制度、特別条項の超過月回数は未実装。過去5か月の欠損を0扱いせず、平均の共通判定を持ちます。実際の労務判断には各会社の制度・協定・運用を確認してください。法情報の確認日2026-10-04、[参考一次資料](references.md)。

## 保存とテスト

保存／読込はブラウザーのローカル領域1件。完全状態を保存し、読込時は停止。版7以外、所定改変、進路や資源矛盾、台帳不整合、破損を拒否して現在状態を保持します。旧版の保存領域は今回版へ移行しません。

`node --test tests/*.test.mjs`で決定論的な正常運行、2戦略、全停止案、配線、勤務境界、保存、実時間進行、DOMスタブを検証。`node verification/reviewer-probe.mjs`で差分指令4680組、3案比較、現地C4交代／遠隔C2拒否、後処理と保存継続を確認。`node verification/server_check.mjs`でローカル配信。配布ZIPはCRCとsource-manifestの全ファイル一致を確認しています。[今回の検証記録](QA.md)を参照してください。過去のブラウザー合格を今回版の合格として流用していません。

配線構造の参考：きたまと「配線略図.net」小田急電鉄多摩線（CC BY 4.0）、日本信号、JRTT。図自体は転載せず、本作の路線・設備・ダイヤ・人物はゲーム向けに独自設計。[著作者・URL・適用範囲](references.md)。

今回の評価修正は法定時間外増分も採点対象とし、所定終業超過との重複を除きます。攻略の実測は[ネタバレ資料](strategy.md)、最終実行証拠は[検証記録](QA.md)。最終版で正常無操作と障害復旧の両方をブラウザー操作で完走確認済みです。保存形式7は旧版6の採点漏れ状態を安全に拒否します。
