# 折り返しの先へ

架空の近郊鉄道「青葉線」の指令員として、部分運転、段階再開、編成と乗務員の配置復旧を行う日本語のブラウザーゲームです。線路が開いても成功にはなりません。中央―森ヶ丘の旅客運行を実際に両方向各2本完了し、西側と東側に編成を戻してください。

## ブラウザーで遊ぶ

公開先： https://velgail.github.io/orikaeshi-no-saki/

GitHub Pagesの初回配信には数分かかる場合があります。

## ローカル起動（Windows / Mac / Linux）

1. このリポジトリをダウンロードして解凍するか、cloneします。
2. **既にNode.jsがある環境**では、そのフォルダーでターミナルを開き `node server.mjs` を実行します。`npm install` は不要です。
3. 一般的なデスクトップブラウザーで **http://127.0.0.1:8765** を開きます。終了はターミナルで Ctrl+C。

Node.jsの代わりに既存のPython 3でも `python3 -m http.server 8765 --bind 127.0.0.1`（Windowsでは `py -m http.server 8765 --bind 127.0.0.1`）で起動できます。HTMLの直接ダブルクリックではJavaScriptモジュールを読み込めないため、ローカルサーバーを使ってください。NodeもPythonもない場合は、この納品物だけでは起動できません。本作はソフトウェアをインストールしません。

プレイ時のインターネット接続・外部API・CDN・フォント取得は不要です。参照資料リンクは閲覧時だけ外部サイトへ移動します。ソースとゲームデータはすべてこのフォルダーにあります。

## 最初の一手

「指令卓へ」→「運転開始」。T1の行先を学園前にして「発車・運用指定」。1分送りで位置・乗務時間・輸送量を観察してください。08:05に川原―東川原が閉鎖、08:20に東向き、08:35に全線が再開します。停止中に読む時間はゲーム内では経過しません。1倍は実時間1秒につきゲーム内1分、4倍は1秒につき4分です。

列車・編成一覧か略図をクリックして対象を選びます。操作の横に所要時間、輸送効果、不可理由を表示します。各駅3分走行＋1分停車、折り返し3分、交代2分、休憩8分。行先を再指定するには駅で抑止してください。自動折り返しは明示的にONにした列車だけ有効で、抑止で解除します。運転開始時は全列車OFFです。自動往復は運用の両端が折り返し可能駅（中央・学園前・東川原・新都心・森ヶ丘）の場合だけONにできます。桜町・川原・丘の上へは自動OFFで片道運用を指定し、到着後は同じ方向へ進んで折り返し駅へ移動してください。途中駅でONにする場合も運用の両端を検査します。

乗務時間上限は走行36分。発車判断では停車時間も含めた所要時間で余裕を見ます。中央・新都心・森ヶ丘で休憩できます。交代はこの3駅と学園前・東川原で、駅に休憩済みの待機乗務員が必要です。森ヶ丘のF4は予備編成で、最初に「交代・予備投入」が必要です。

待機乗務員は列車に同乗させて運べます。運用を指定する前に「待機乗務員同乗」を押し、通常の旅客運行か回送で目的地へ届けます。途中駅で降ろす場合は停車中に抑止し「同乗乗務員降車」。担当を交代した古い乗務員はその駅に残るため、拠点まで同乗で連れ帰ると休憩できます。配線・乗務員の位置・区間占有を解消する手段であり、瞬間移動はありません。

旅客は次の駅までの移動として簡略化し、各区間最大80人を輸送します。総待ち時間は毎分の全駅待ち人数の累積（人分）。評価は輸送人・区間 − 総待ち人分÷100 ＋ 復旧達成500、下限0。結果には両方向の完了本数、配置、08:35時点の乗務余裕、操作履歴を表示します。未達のまま10:00になると終了します。

列車別時刻表は、プレイヤーが運用を指定した時刻を予定発車として、各駅の予定着・発を確定します。既定の自動ダイヤはありません。競合待ちでも予定を変更せず、実発車・到着実績・遅れを表示します。駅別詳細を開くと途中駅も確認できます。抑止や乗務余裕不足で未完了の運用を解除すると「運休」として残ります。設備復旧予定は別表です。

保存形式は版2です。不正な自動往復や、折り返し不可駅で実到着方向と異なる保存は拒否します。旧版の保存は読み込まず、日本語の理由を表示して現在の状態を保持します。

ゲーム内「ルール」で詳細を確認できます。「保存」はブラウザーのローカル領域に全状態を1件保存し、「読込」は停止状態から再開します。ブラウザーやURLが違うと保存は共有されません。保存不可・破損・異なる形式では日本語の理由を示し、現在の状態を保持します。「やり直し」「再プレイ」で最初へ戻れます。
